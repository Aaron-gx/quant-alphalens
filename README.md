# 基金·股票 AI 预测引擎

基于 LLM 的 A股/基金/港股通预测工具：结构化涨跌预测 + 舆情相关性筛选 + 到期自动对账 +
自学习概率校准 + 模拟盘。设计文档见 `基金股票AI预测工具-策划书.md`。

## 功能

- **涨跌预测**：次日/一周/一月/一季度的 涨/平/跌 概率分布 + 情景推演 + 操作建议（结构化 JSON 落库）
- **三引擎融合**：LLM 推理 + 量化基线（内置纯 numpy 分类器，装了 lightgbm 自动升级）+ 自学习校准层
- **舆情相关性筛选**：基金/ETF 先推导"真实舆情范围"（重仓股 + 跟踪指数 + 主题），
  再按相关度分层筛选加权，避免用大盘情绪冒充基金舆情
- **自学习校准**：到期对账结果 → 训练样本 → 元模型/温度缩放校准概率，
  样本外 Brier 与命中率对基准留痕；样本不足时如实标注"未校准"
- **预测验证**：到期自动对账，命中率、Brier 校准分、置信度分桶看板
- **模拟盘**：虚拟账户（T+1、佣金印花税）、净值曲线、胜率/回撤/夏普；`ai_signal` 账户支持 AI 信号自动调仓
- **用户画像**：风险偏好/持仓/交易风格/常犯错误持久化，自动注入每次分析
- **定时任务**：盘前简报、盘中异动、尾盘 AI 调仓、盘后预测、到期对账、净值快照、情报补打分、每日重训
- **API**：FastAPI REST 接口（X-API-Key 鉴权），供聊天机器人调用；`bots/bot_server.py` 为指令适配示例

## 快速开始

```bash
python -m venv .venv
.\.venv\Scripts\activate          # Windows
pip install -r requirements.txt
cp config.example.toml config.toml  # 填入你的 LLM api_key（推荐 DeepSeek）
```

三个进程（也可 `docker compose up -d` 一把起）：

```bash
# 1. 启动后端 API（端口 8000）
uvicorn api.main:app --port 8000

# 2. 启动 AlphaLens AI 前端（主力控制台，端口 3000）
cd frontend && npm run dev          # http://localhost:3000

# 3. 定时任务调度器（时间表见 config.toml [schedule]）
python -m jobs.scheduler
```

量化引擎默认开启，无需额外依赖（内置纯 numpy 多分类模型）；
`pip install lightgbm` 后会自动切换到 LGBM 获得更强的非线性拟合能力。

## 代码/指数输入

`600519`（A股）· `510300`（场内ETF）· `110022`（场外基金）· `00700`或`HK00700`（港股）· `上证指数`（指数名）
界面内置名称搜索，不必记代码。输入基金代码会额外展示基金档案（类型/经理/公司/规模、
阶段收益、重仓股、跟踪指数）与"该基金真正相关的舆情范围"。

## 舆情相关性是怎么判的

一条情报进入模型前会先算一个 0~1 的**相关度**，分三层：

| 层级 | 判定依据 | 分值 | 处理 |
|------|----------|------|------|
| 直接相关 | 命中标的代码 / 名称 | 0.95~1.0 | 全额参与情绪投票 |
| 间接相关 | 命中重仓股（按占净值比 0.55~0.85）、基金公司 | 0.5~0.85 | 按相关度折减权重 |
| 环境相关 | 跟踪指数/主题词 0.6、宏观政策 0.35、泛快讯 0.15 | 0.15~0.6 | 低于门槛（默认 0.30）只留档不投票 |

LLM 打分时同时输出 `relevance`（1-5），最终相关度取"规则分与 LLM 分的高者"（召回优先）。
聚合时权重 = 强度 × 预期偏离度 × 相关度折扣，并同时给出两个口径：
**标的舆情**与**全市场情绪**，两者之差说明该标的是"独立驱动"还是"随大盘漂"。

## 自学习闭环（预测率如何被持续改进）

```
预测落库(概率+舆情分) → 到期按真实收盘价对账 → 写入 CalibSample(引擎概率→真实方向)
        ↑                                                     ↓
   新预测概率被校准 ← 每日重训校准层（时序切分验证） ← 累积样本
```

- **两类样本分池**：`eval`（真实到期对账，最可信）与 `walk_forward`（量化模型历史上
  滚动"只用过去预测未来"的样本外结果，冷启动即可用）；LLM 池与量化池分开训练，防止
  数量悬殊的样本互相带偏。
- **三级模型**：样本 <40 条 → `identity`（如实标注未校准）；≥40 → 温度缩放；
  ≥80 → 元模型（逻辑回归，输入引擎概率/舆情分/置信度）。每级都做时序切分，
  样本外 Brier 与命中率写入 `model_training_runs`，构成学习曲线。
- **不硬用坏模型**：校准若打不过"多数类基准命中率"，会自动退回 `identity`。
  例如当前 600 条日频样本下，校准层判定样本外 Brier 无改善而保持 identity ——
  这是系统的诚实回答：日频方向预测信噪比低，需要更多样本或更强的特征。

## 主要配置

```toml
[predict]
use_quant = true        # 量化引擎交叉验证（内置纯 numpy 模型，无需额外依赖）
quant_weight = 0.35     # 融合权重
use_calibration = true  # 自学习校准（无样本时自动跳过）
calib_ttl_days = 3      # 校准包有效期
flat_threshold_pct = 1.0  # "平盘"阈值：直接影响类别分布与可学到的信号强度

[intel]
min_relevance = 0.30    # 舆情入选门槛（0~1）
```
